부모님이 올려 준 단원

단원 파일을 직접 가져오기

부모님이 만든 단원 데이터(JSON 파일)를 이 기기에 넣어요. 교재 내용이라서 인터넷에 올라가지 않고 이 기기에만 저장돼요.

먼저 「단원」 화면에서 단원을 골라 「시험지 만들기」를 눌러 주세요.

⚙ 더 설정

꾸미기

좋아하는 모양을 골라요. 태블릿 화면만 바뀌고, 인쇄하는 시험지는 그대로예요.

아이 이름 표시

단원 데이터에는 「아이 A·B」만 적혀 있어요. 이 기기 화면에서만 이름을 함께 보여 줘요. 시험지에는 들어가지 않아요.

부모님 단원 연결

백업

브라우저 데이터를 지우면 가져온 단원과 틀린 단어 표시가 사라져요. 백업 파일을 만들어 두면 다시 넣을 수 있어요. (부모님이 올려 준 단원은 백업에 들어가지 않고, 연결되어 있으면 저절로 다시 받아져요.)

이 기기에서 지우기

직접 가져온 단원만 지워요. 부모님이 올려 준 단원은 연결을 끊을 때 함께 지워져요.

고칠 곳 목록

키보드 확인 (태블릿에서 풀기 전에)

켜 두면 시험과 외우기 입력칸에서 기기 키보드 대신 화면 아래 앱 자판이 떠요. 대문자는 ⇧ 를 누르고 쓰면 한 글자만 대문자가 돼요. 아래 칸은 기기 키보드를 확인하는 곳이라 기기 키보드가 떠요.

S펜으로 입력칸에 바로 쓰기(부모님 확인용)
  1. 태블릿 설정에서 S펜 메뉴의 「S펜으로 텍스트 입력」을 켜요(메뉴 이름은 기기마다 조금 달라요).
  2. 시험·외우기 입력칸을 S펜으로 누르면 앱 자판이 뜨지 않고 펜으로 바로 써져요. 손가락으로 누르면 앱 자판이 떠요.
  3. 다른 태블릿에서 처음 쓸 때는 아래 칸에 일부러 틀린 철자 freind 를 펜으로 써서 그대로 남는지 확인해 주세요. friend 로 바뀌면 틀린 철자가 맞게 고쳐져 채점이 틀려지므로 펜 대신 자판을 써요.

아래 칸에 american 이라고 소문자로 써 보세요. 키보드가 첫 글자를 대문자로 바꾸거나 단어를 고치면, 정답을 써도 틀린 것으로 채점돼요.

소리 확인 (듣고 쓰기 전에)

「외우기 → 듣고 쓰기」는 태블릿의 영어 음성으로 단어를 읽어 줘요. 아래 버튼을 눌러 영어 소리가 나는지 확인해 주세요. 소리가 작으면 태블릿 음량(미디어 음량)을 올려 주세요.

안내

  • 입력 칸에서 자동 대문자와 자동 완성이 켜져 있으면 철자 연습이 어려워요. 삼성 키보드는 설정에서 「자동 대문자」와 「예측 텍스트」를 꺼 주세요.
  • 집 채점은 항상 엄격해요. 철자 한 글자, 대소문자, -ed·-s가 빠지면 0점이에요.
