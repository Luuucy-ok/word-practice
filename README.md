# 단어 연습

영어 학원 단어 시험(월·수)과 chunk 시험(금) 연습지를 만들고 인쇄하는 정적 웹앱입니다. 서버와 사용료가 없습니다.

## 쓰는 법

1. 앱을 엽니다(GitHub Pages 주소, 또는 `index.html` 을 브라우저에서 열기).
2. 「단원」 화면에서 부모님이 만든 단원 데이터(JSON)를 가져옵니다. 데이터는 이 기기 브라우저에만 저장됩니다.
3. 단원의 「시험지 만들기」를 누르면 시험지와 정답지가 나옵니다. 「새 시험지 만들기」를 누를 때마다 순서가 바뀝니다.
4. 「인쇄 / PDF 저장」으로 인쇄합니다.

## 부모님 단원 자동 받기(선택)

부모님이 준 연결 링크(`…/#connect=…`)를 이 기기에서 한 번 열고(링크 하나를 두 아이가 같이 쓰며, 열면 「아이 A / 아이 B」 중에서 고릅니다) 「연결하기」를 누르면, 이후에는 앱을 열 때마다 새 단원이 저절로 들어옵니다. 단원은 이 저장소가 아닌 별도의 비공개 저장소에서 읽기 전용 열쇠로 받아 오며, 열쇠와 받은 단원은 이 기기 브라우저에만 저장됩니다. 연결하지 않아도 위의 직접 가져오기를 그대로 쓸 수 있습니다. 받는 곳은 `js/sync.js` 에 고정되어 있어 링크로 바꿀 수 없습니다. 이 주소(`luuucy-ok.github.io`)에는 외부 스크립트를 넣은 다른 페이지를 두지 않습니다(같은 브라우저 저장소를 공유할 수 있기 때문).

## 태블릿에서 풀기와 자동 채점

- 시험지 만들기에서 「태블릿에서 풀기」를 누르면 방금 만든 종이 시험지와 같은 문항(같은 시험지 번호)을 화면에서 풉니다.
- 채점은 집 채점 규칙(0점 방식)을 따릅니다. 대소문자를 구분하고, 앞뒤 공백은 무시하며, 단어 사이의 연속 공백은 하나로 봅니다. 구절 앞뒤의 문장 부호는 보지 않습니다.
- 틀린 단어와 chunk 는 약한 목록에 자동으로 들어가고, 약한 항목을 화면 시험에서 연속 2번 맞히면 빠집니다. 점수는 단원 카드에 최근 3개까지 보입니다.
- 풀던 답은 이 기기에 저장되어, 같은 시험지 번호로 다시 열면 이어서 풉니다.
- 입력칸은 자동 대문자·자동 수정·맞춤법 검사를 끕니다. 기기 키보드가 그래도 글자를 바꾸면 설정의 「키보드 확인」에서 알 수 있습니다.

## 외우기 (카드 넘기기, 듣고 쓰기, 첫 글자 힌트 쓰기, 글자 순서 맞추기, chunk 블록 맞추기)

- 단원 카드의 「외우기」에서 방법과 범위(전체 또는 약한 항목만)를 고릅니다. chunk 단원은 Key Vocabulary 와 chunk 문장을 따로 고를 수 있습니다. 고른 방법은 이 기기에 기억됩니다.
- 카드 넘기기: 앞면(뜻 또는 영어)을 보고 떠올린 뒤 뒤집어 확인하고 「알아요/몰라요」를 누릅니다. 몰라요 카드는 뒤에 다시 나옵니다. 스스로 판단하는 연습이라 약한 목록과 점수 기록은 바꾸지 않습니다.
- 듣고 쓰기: 기기 음성으로 단어(chunk 는 콜로케이션 전체나 문장 전체)를 들려주고, 한글 뜻을 보며 빈칸을 씁니다. 채점 규칙은 화면 시험과 같고, 틀린 것은 뒤에 다시 나옵니다. 처음에 틀린 것은 약한 목록에 들어가며, 빼는 것은 화면 시험에서만 합니다.
- 첫 글자 힌트 쓰기: 뜻과 단어마다 첫 글자·글자 수 힌트(`e______`)를 보고 씁니다. 채점과 약한 목록 규칙은 듣고 쓰기와 같고, 소리는 확인한 뒤에 들려줍니다.
- 글자 순서 맞추기: 뜻을 보고 섞인 글자를 눌러 단어를 만듭니다(chunk 단원은 Key Vocabulary 단어). 놓은 글자를 다시 누르면 빠지고, 다 놓으면 저절로 확인합니다.
- chunk 블록 맞추기(chunk 단원만): 콜로케이션 전체와 chunk 문장의 빈칸 부분을 단어 블록으로 섞어, 순서대로 눌러 맞춥니다. chunk 문장은 앞뒤 문장이 그대로 보입니다.
- 맞추기 두 가지는 조각을 고르는 연습이라 약한 목록을 바꾸지 않습니다. 틀린 것은 뒤에 다시 나옵니다.
- 소리는 크롬의 음성 합성(Web Speech API)을 씁니다. 설정의 「소리 확인」에서 영어 음성이 있는지 확인합니다.
- 단원 데이터의 `note` 는 부모님용 메모라서 아이 화면에 보여 주지 않습니다.

## 꾸미기와 스티커

- 설정의 「꾸미기」에서 아이마다 모양을 고릅니다: 기본, 🌷 파스텔 다이어리, 🍓 딸기 우유, ✨ 별빛 마법. 두 아이를 함께 연결한 기기는 「지금 보는 아이」에 따라 바뀌고, 외우기·풀기 화면은 그 단원 주인의 모양으로 열립니다. 연결하지 않은 기기는 「이 기기」 하나로 고릅니다.
- 꾸밈은 태블릿 화면에만 적용합니다. 인쇄 시험지는 그대로입니다. 기본 모양은 어두운 화면을 따르고, 나머지 셋은 밝은 화면으로 고정합니다.
- 맞히면 효과음과 작은 색종이, 다 하면 큰 색종이와 축하 효과음이 나옵니다. 효과음은 설정에서 끌 수 있습니다(소리 파일 없이 Web Audio 로 만듦). 움직임 줄이기를 켠 기기에서는 색종이를 띄우지 않습니다.
- 외우기를 끝까지 하거나 태블릿 시험을 채점하면 스티커를 하나 받고, 만점이면 하나 더 받습니다(틀린 문항만 다시 풀기는 제외). 스티커는 단원 화면 위의 스티커 판에 모이고, 기기 설정과 함께 백업에 들어갑니다. 백업을 다시 가져오면 아이마다 합쳐서 그 뒤에 받은 스티커가 지워지지 않습니다.
- 제목·버튼 글꼴은 Jua, 영어 글자 조각은 Nunito 입니다. 둘 다 SIL Open Font License 이고, 자주 쓰는 한글 2,350자와 영문만 남겨 `fonts/` 에 넣었습니다(라이선스 파일 포함). 영어 단어는 철자가 헷갈리지 않도록 손글씨 느낌 글꼴을 쓰지 않습니다.

## 확인 표의 고칠 곳 적기

- 단원의 「확인 표」에서 「고칠 곳 적기」를 누르고 틀린 칸을 누르면 바른 내용을 적을 수 있습니다. 앱의 단원은 바뀌지 않습니다.
- 「수정 목록 복사」로 만든 글을 부모님 작업실에 보내면, 원본 단원 데이터를 고쳐 다시 올립니다. 고친 단원을 받으면 그 칸은 목록에서 저절로 빠집니다.
- 문장 출처 규칙과 해석 필수 여부는 여기서 바꿀 수 없습니다.

## 틀린 단어 표시와 재시험지

- 단원 카드의 「틀린 단어 표시」(또는 시험지 만들기 화면의 「틀린 단어 표시하기」)에서 시험에서 틀린 단어를 체크합니다. chunk 단원은 Key Vocabulary 와 chunk 문장을 따로 체크합니다.
- 표시는 이 기기에만 저장되고, 부모님 단원을 새로 받아도 남습니다. 백업 파일에 들어가고 다시 가져올 때 합쳐집니다.
- 시험지 만들기에서 「약한 단어만」(단어) 또는 「약한 항목만」(chunk)을 고르면 표시한 것만으로 재시험지가 나옵니다. 단원의 문장 규칙은 그대로 지킵니다. chunk 는 표시한 항목을 전부 내는 「범위 전체」 방식입니다. 보통 방식의 chunk 시험지는 표시한 항목을 먼저 뽑습니다.
- 다시 맞히게 되면 같은 화면에서 체크를 풀어 표시를 지웁니다.

## 지키는 규칙

- 단원 데이터에는 누구 것인지(`owner`), 문장 출처 규칙(`sentence_sources`), 해석 필수 여부(`require_sentence_ko`)가 있어야 합니다. 없으면 시험지를 만들지 않습니다. chunk 데이터는 `owner` 와 `hint`(none 또는 first)가 필요합니다.
- 문장 출처 규칙은 앱에서 바꿀 수 없습니다. 데이터에 적힌 대로만 출제합니다.
- 교재와 대조하기 전 데이터(`verified: false`)는 화면과 시험지에 「교재 대조 전」 표시가 붙습니다.
- 집 채점은 항상 엄격합니다. 철자 한 글자, 대소문자, -ed·-s 빠뜨림은 0점입니다.

## 교재 데이터는 올리지 않습니다

이 저장소에는 앱 코드만 있습니다. 교재 단어·문장(저작권)과 백업 파일은 `.gitignore` 로 막혀 있습니다.

## 규칙 점검

```
node test/run.js "<단원 데이터 폴더>" "<출력 폴더(선택)>"
```

폴더의 모든 데이터로 시험지를 수천 번 만들어 규칙 위반이 없는지, 필수 항목이 없는 데이터를 거부하는지 확인합니다.

```
node test/sync.js "<단원 데이터 폴더>"
node test/e2e-sync.js "<단원 데이터 폴더>" "<스크린샷 폴더>"
```

가짜 GitHub 응답으로 연결 링크, 자동 받기, 오류 안내, 연결 끊기를 확인합니다(인터넷 접속 없음).

```
node test/weak.js "<단원 데이터 폴더>"
node test/e2e-weak.js "<단원 데이터 폴더>" "<스크린샷 폴더>"
node test/sw-fresh.js
```

`node test/quiz.js "<단원 데이터 폴더>"`, `node test/e2e-solve.js "<단원 데이터 폴더>" "<스크린샷 폴더>"` 는 화면 풀기 채점 규칙과 푸는 화면을 확인합니다. `node test/study.js "<단원 데이터 폴더>"`, `node test/e2e-study.js "<단원 데이터 폴더>" "<스크린샷 폴더>"` 는 외우기 규칙과 화면을 확인합니다(기기 음성은 가짜로 바꿔 들려준 글자를 확인). `node test/e2e-fun.js "<단원 데이터 폴더>" "<스크린샷 폴더>"` 는 꾸미기, 효과음, 색종이, 스티커, 백업 합치기를 확인하고 테마마다 스크린샷을 남깁니다. 화면 점검은 스크린샷 폴더를 점검마다 따로 주세요. 아래 셋은 틀린 단어 저장·백업·재시험지 규칙, 표시 화면, 새로 올린 앱이 늦게 반영되지 않는지를 확인합니다.
