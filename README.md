# 단어 연습

영어 학원 단어 시험(월·수)과 chunk 시험(금) 연습지를 만들고 인쇄하는 정적 웹앱입니다. 서버와 사용료가 없습니다.

## 쓰는 법

1. 앱을 엽니다(GitHub Pages 주소, 또는 `index.html` 을 브라우저에서 열기).
2. 「단원」 화면에서 부모님이 만든 단원 데이터(JSON)를 가져옵니다. 데이터는 이 기기 브라우저에만 저장됩니다.
3. 단원의 「시험지 만들기」를 누르면 시험지와 정답지가 나옵니다. 「새 시험지 만들기」를 누를 때마다 순서가 바뀝니다.
4. 「인쇄 / PDF 저장」으로 인쇄합니다.

## 지키는 규칙

- 단원 데이터에는 누구 것인지(`owner`), 문장 출처 규칙(`sentence_sources`), 해석 필수 여부(`require_sentence_ko`)가 있어야 합니다. 없으면 시험지를 만들지 않습니다. chunk 데이터는 `owner` 와 `hint`(none 또는 first)가 필요합니다.
- 문장 출처 규칙은 앱에서 바꿀 수 없습니다. 데이터에 적힌 대로만 출제합니다.
- 교재와 대조하기 전 데이터(`verified: false`)는 화면과 시험지에 「교재 대조 전」 표시가 붙습니다.
- 집 채점은 항상 엄격합니다. 철자 한 글자, 대소문자, -ed·-s 빠뜨림은 0점입니다.

## 교재 데이터는 올리지 않습니다

이 저장소에는 앱 코드만 있습니다. 교재 단어·문장(저작권)과 백업 파일은 `.gitignore` 로 막혀 있습니다.

## 규칙 점검

```
node test/run.js "<단원 데이터 폴더>" "<출력 폴더(선택)>"
```

폴더의 모든 데이터로 시험지를 수천 번 만들어 규칙 위반이 없는지, 필수 항목이 없는 데이터를 거부하는지 확인합니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html`, `css/app.css`, `js/app.js` | 화면 |
| `js/word.js` | 단어 시험지 규칙 |
| `js/chunk.js` | chunk 시험지 규칙 |
| `js/store.js` | 기기 안 저장과 백업 |
| `js/util.js` | 공통 도구 |
| `sw.js`, `manifest.webmanifest` | 홈 화면에 추가와 오프라인 |
